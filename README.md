# Projector

Plattform für kollektive Projekte: Projekte starten, gemeinsam brainstormen,
zusammen umsetzen. Projekte durchlaufen drei Phasen — 💡 Brainstorming,
🚧 Laufend, ✅ Fertig.

- **Design:** `docs/design/teilprojekt-a-design.md`
- **Umsetzungsplan:** `docs/plans/teilprojekt-a-plan.md`

## Technik

Next.js (App Router) + TypeScript + Tailwind CSS, Supabase (Auth + Postgres,
Region Frankfurt), Hosting auf Vercel.

## Lokal starten

```bash
npm install
npm run dev
```

Danach läuft die App auf http://localhost:3000.
